# 标题 BGM

替换标题/菜单相关的音乐与提示音。文件缺失时会自动用原版音效。

## 目录与文件

目录：`TitleBGM/`

| 文件 | 行为 | 说明 |
|------|------|------|
| `startFX.*` | 开场音效，单次播放 | 进标题时先播这个，播完自动切到 `title.*` |
| `title.*` | 标题/菜单循环 | 主菜单背景音乐 |
| `start.*` | 进入基地提示，单次播放 | 在 HomeBGM 设置中可开关（"启用进入基地音效"） |
| `death.*` | 死亡提示，单次播放 | 玩家死亡时触发 |
| `extraction.*` | 撤离成功缺省回退 | 当 `Extraction/success.*` 不存在且选择"成功替换"模式时 |

## 设置

- **进入基地提示音**：ModConfig → HomeBGM → "启用进入基地音效"。关闭后不拦截原版 stg_map_base Stinger。

## 常见问题

- **start/death 不生效**：确认文件存在且扩展名正确；检查是否关闭了设置开关。
- **声音太大/太小**：标题相关没有独立音量控制，可用外部工具批量调整文件音量。
