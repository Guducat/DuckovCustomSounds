# 更新日志

## 2025-11-02 v1.0

- 修复：枪械音量异常的问题。
- 修复：针剂与药品的使用逻辑。
- 修复：特定情况下物品使用的音效异常停止。
- 新增：可自定义“加载中 / 加载完成”BGM。
- 新增：实验性的“场景 BGM”。
- 新增：枪械与近战武器的差分音效（支持同一事件使用 `xxx_1.mp3`、`xxx_2.mp3`…）。

小提示：以上新增内容默认随“音乐”音量生效；与 Boss BGM 同时出现时会自动协调优先级。

## 2026-04-25 v2.1.0

- 新增：修复 `TitleBGM/startFX.*` 不播放的问题。
- 新增：*音乐*文件支持 `.flac`、`.ogg`、`.wav` 等 18 种格式，不再局限于 `.mp3`。
- 新增：多个模块增加独立音量滑块（0~200%），随"音效"总线取值，可在 ModConfig 中调节。
- 新增：日志等级运行时热切换——在 ModConfig 或 `settings.json` 中改日志等级，无需重启立即生效。
- 新增：脚步与冲刺（Dash）音效可同时播放，再也不会互相打断了。

- 修复：撤离成功音效不再仅对少数地图生效——现在理论上支持所有地图的撤离短音乐拦截和替换。
- 修复：加载界面无法触发音效的问题。
- 修复：物品使用中快速取消后，音效错误地持续播放的问题。
- 修复：脚步声触发后会意外遮断冲刺（Dash）音效、冲刺冷却期间完全静音的问题。

- 改进：场景音乐支持中文，例如 `零号区.mp3` ，参见日志。
- 改进：ModConfig 设置界面全面中文化——各模块分组改为中文名称，下拉选项也本土化了。
- 改进：旧版 `settings.json` 配置键可在新版中继续使用，升级不会丢设置。
- 改进：日志输出加了模块名前缀，你能看出每条日志来自哪个子模块，排查更方便。
- 改进：Boss BGM 与撤离音效新增独立音量滑块（0~100%）。
- 改进：所有模块文档重写，更简洁、更统一、更易读。
- 改进：GitHub Actions 自动部署 VitePress 文档站，v2.* 标签推送自动发布 DLL。

- 移除：未启用的"击杀反馈"模块相关代码与文档入口。

## 2026-04-26 v2.1.1
- 改进：改进了场景进入音乐的匹配逻辑，不容易丢失进入场景的音乐了。

## 2026-04-27 v2.2.0

- 新增：更多手雷音效兼容——保留旧版事件回退，按来源与 TypeID 路由到独立音效，支持无事件注入与严格变体匹配。
- 改进：手雷音效文档与声音包生成器同步更新。

## 2026-04-27 v2.2.1

- 新增：环境音拦截的 ModConfig UI，以及独立的风暴阶段提示音拦截开关（`Music/Stinger/stg_storm_1`、`stg_storm_2`）。

## 2026-04-27 v2.3.0

- 新增：击中与击杀音效反馈模块，支持命中与击杀事件替换、ModConfig 开关与音量调节，反射诊断补充序列化字段覆盖。

## 2026-08-12 v2.3.1

- 修复：Boss 处于触发距离外时不再抑制场景 BGM，避免场景音乐与 Boss 音乐同时静音。
- 改进：Boss 离开触发距离、注销或场景清理后自动恢复场景 BGM；运行中调整触发距离立即生效。

## 2026-08-14 v2.3.3

- 修复：Boss→Boss 切换（如传送到另一个 Boss 附近）后场景 BGM 丢失——Boss 解除压制时若场景循环 BGM 已意外停止会自动重建（自愈）；场景切换清理路径不触发重建。
- 修复：撤离倒计时模式与场景 BGM 双重播放——倒计时期间场景 BGM 快速降音量（不停止），取消撤离后平滑恢复；撤离成功仍由游戏转场 StopBGM 处理。
- 文档：README 待办与已知问题整理为「TODO 待办与改进项」。
