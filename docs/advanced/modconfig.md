# ModConfig 配置选项

所有配置项可通过游戏内 ModConfig UI 修改。除了声音包切换需重启，其他选项即时生效。

## 物品音效 (Item)

| 配置项 | 类型 | 默认 | 说明 |
|--------|------|------|------|
| 启用自定义物品音效 | 布尔 | 开 | 总开关 |
| 音量倍率 | 浮点 | 1.0 | 0~2 |
| Action 最短可听时间 | 浮点 | 0.35 秒 | 0~3 |
| 启用 食物/饮料 | 布尔 | 开 | |
| 启用 绷带/药品 | 布尔 | 开 | 含 meds 类别 |
| 启用 注射器 | 布尔 | 开 | |

## 敌人语音 (EnemyVoice)

| 配置项 | 类型 | 默认 | 说明 |
|--------|------|------|------|
| 允许 NPC-对-NPC 战斗语音 | 布尔 | 开 | |
| 语音触发模式 | 枚举 | 原版 | 原版 / 仅玩家相关 / 混合 |
| 语音音量倍率 | 浮点 | 1.0 | 0~2 |

## 主页 BGM (HomeBGM)

| 配置项 | 类型 | 默认 | 说明 |
|--------|------|------|------|
| 启用主页 BGM | 布尔 | 开 | |
| 启用进入基地音效 | 布尔 | 开 | 控制 start.mp3 |
| 音乐音量 | 整数 | 100% | 0~100 |
| 使用 SFX 总线 | 布尔 | 关 | 实验性，走 SFX 而非 Music 总线 |
| 下一首随机播放 | 布尔 | 关 | |
| 上一首也随机 | 布尔 | 关 | 需先开启随机 |
| 避免连续重复 | 布尔 | 开 | 随机模式下生效 |
| 自动播放下一曲 | 布尔 | 开 | |

## 场景 BGM (SceneBGM)

| 配置项 | 类型 | 默认 | 说明 |
|--------|------|------|------|
| 启用场景音乐系统 | 布尔 | 开 | |
| [Enter] 启用进入场景 BGM | 布尔 | 开 | |
| [Enter] 进入音乐音量 | 浮点 | 80% | 0~100 |
| [Loop] 启用循环场景 BGM | 布尔 | 开 | |
| [Loop] 循环音乐音量 | 浮点 | 60% | 0~100 |
| [Loop] 覆盖默认场景音乐 | 布尔 | 开 | |

## Boss BGM (BossBGM)

| 配置项 | 类型 | 默认 | 说明 |
|--------|------|------|------|

| 触发距离 | 浮点 | 40 米 | 10~200 |
| 首领音乐音量 | 浮点 | 70% | 0~100 |

## 撤离 BGM (ExtractionBGM)

| 配置项 | 类型 | 默认 | 说明 |
|--------|------|------|------|
| 撤离音乐模式 | 枚举 | 关闭 | 关闭 / 倒计时音效 / 成功替换 |
| 撤离音效音量 | 浮点 | 100% | 0~100 |

## 声音包 (SoundPack)

| 配置项 | 类型 | 默认 | 说明 |
|--------|------|------|------|
| 声音包 | 下拉列表 | Default | 选择后需重启生效 |

## 打开 ModConfig

游戏内 ESC → Mod 设置 → DuckovCustomSounds。
