# ModConfig 配置选项

所有配置项可通过游戏内 ModConfig UI 修改。除了声音包切换需重启，其他选项即时生效。每个分组在 UI 中以 `DCSxxx | 中文名` 显示（如下各节标题所示）。

## 物品音效 (DCSItem)

| 配置项 | 类型 | 默认 | 说明 |
|--------|------|------|------|
| 启用自定义物品音效 | 布尔 | 开 | 总开关 |
| 音量倍率 | 浮点 | 1.0 | 0~2 |
| Action 最短可听时间 | 浮点 | 0.35 秒 | 0~3 |
| 启用 食物/饮料 | 布尔 | 开 | |
| 启用 绷带/药品 | 布尔 | 开 | 含 meds 类别 |
| 启用 注射器 | 布尔 | 开 | |

## 命中与击杀音效 (DCSHitAndKill)

| 配置项 | 类型 | 默认 | 说明 |
|--------|------|------|------|
| 启用命中与击杀音效 | 布尔 | 开 | 总开关 |

| 提示音冷却毫秒 | 浮点 | 30 | 0~500 |
| 受击音效冷却毫秒 | 浮点 | 120 | 0~1000 |

## 环境音拦截 (DCSAmbientIntercept)

| 配置项 | 类型 | 默认 | 说明 |
|--------|------|------|------|
| 启用环境音拦截（实验性） | 布尔 | 关 | 拦截 `Amb/amb_*` 环境音，`Amb/amb_storm` 放行 |
| 拦截风暴阶段提示音（实验性） | 布尔 | 关 | 拦截 `Music/Stinger/stg_storm_1` 与 `Music/Stinger/stg_storm_2` |

## 音效日志 (DCSLogging)

| 配置项 | 类型 | 默认 | 说明 |
|--------|------|------|------|
| 启用日志输出 | 布尔 | 开 | 全局总开关，关闭后所有模块不再输出 |
| Core / SoundPack / Enemy / Footstep / BGM / HomeBGM / SceneBGM / ExtractionBGM / Gun / Grenade / Item / Melee 日志等级 | 下拉列表 | 信息 | 错误/警告/信息/调试/详细，可热切换 |

注：`HitAndKill` 模块的日志等级**不在**本 UI 分组中，只能通过 `settings.json` 的 `logging.modules.HitAndKill.level` 设置。

## 声音包 (DCSSoundPack)

| 配置项 | 类型 | 默认 | 说明 |
|--------|------|------|------|
| 声音包 | 下拉列表 | Default | 选择后需重启生效 |

## 打开 ModConfig

游戏内 ESC → Mod 设置 → DuckovCustomSounds。
